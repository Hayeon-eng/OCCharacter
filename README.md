# Online Content Group 업무 유형 테스트 v9

기존 flat/Vite 구조 유지, 캐릭터를 CSS 도형 조립형에서 파스텔 마스코트 SVG 스타일로 교체한 버전입니다.

## 구조

```text
index.html
main.js
style.css
package.json
README.md
```

## Render Static Site 설정

Build Command:
```bash
npm install && npm run build
```

Publish Directory:
```bash
dist
```

Environment Variable:
```bash
NODE_VERSION=20.19.0
```
